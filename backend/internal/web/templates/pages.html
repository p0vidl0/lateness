Приём сигнала

Без сессии и ключа. Токен в URL — секрет этого ожидания.

{{.IntakeURL}}

Подтверждает ритм: новое окно считается от момента приёма, прогон сбрасывается.

curl -fsS -X POST {{.IntakeURL}} \
  -H 'content-type: application/json' \
  -d '{"outcome":"ok"}'

Вооружает прогон: если ok не придёт в пределах допуска, ожидание станет просроченным. Окно ритма не сдвигается.

curl -fsS -X POST {{.IntakeURL}} \
  -H 'content-type: application/json' \
  -d '{"outcome":"begin"}'

Явный срыв: сразу «Просрочено» и одно уведомление в каждый канал.

curl -fsS -X POST {{.IntakeURL}} \
  -H 'content-type: application/json' \
  -d '{"outcome":"fail","note":"…"}'

Поле note — до 2000 символов. Время берётся с часов сервера.
