# Приглашения

Регистрация закрыта. Аккаунт создаётся только по одноразовой ссылке, она живёт 7 дней.

## Первый администратор в prod

На новой базе администраторов нет. После первого старта `serve` (он создаёт схему):

```bash
LATENESS_DATABASE_URL=… LATENESS_SECRET_KEY=… LATENESS_PUBLIC_URL=https://lateness.example \
  lateness invite -admin -note "первый администратор"
```

Команда печатает ссылку и срок действия. Откройте её и зарегистрируйтесь паролем, через VK ID или Telegram.

В dev то же делает `make invite ADMIN=1`; сид-аккаунт уже администратор.

## Обычная выдача

Администратор на странице «Приглашения» пишет пометку («кому и зачем»), при необходимости отмечает «Администратор», создаёт ссылку и копирует её — показывается один раз. В списке видно состояние каждого приглашения.

## Отзыв

Кнопка «Отозвать» у активного приглашения. Использованное отозвать нельзя: аккаунт уже создан.

## Если ссылка не работает

- «Такого приглашения нет» — ссылка обрезана или скопирована с ошибкой.
- «Приглашение уже использовано, истекло или отозвано» — выдайте новое.
- «Вход только по приглашению» после VK ID или Telegram — человек начал вход со страницы `/login`, а не по ссылке. Нужно открыть ссылку-приглашение и войти через провайдера там. Уже зарегистрированный человек привязывает провайдера в профиле.

Проверка в базе: `SELECT note, is_admin, created_at, expires_at, used_at, revoked_at FROM invites ORDER BY created_at DESC LIMIT 20`.
