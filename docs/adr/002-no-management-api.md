# ADR 002. Без HTTP API управления

## Решение

Управление — только через серверные страницы `serve`. OpenAPI, сгенерированный сервер, ключи API и маршруты `/v1` удалены. Публичным остаётся только приём сигнала `POST /intake/{token}`: это не управление, а способ, которым задача сообщает о себе.

Сценарии живут в `internal/app`. Страницы (`internal/web`) — тонкий слой: разобрать форму, вызвать сценарий, отрисовать шаблон. Integration-тесты вызывают `app.Service` напрямую поверх Postgres.

## Почему так

Сервис в разработке, и у API не было потребителей. Второй вход в те же сценарии удваивал авторизацию (сессия и ключ), контракт и тесты. Если API понадобится, его можно добавить поверх тех же сценариев `app`.
