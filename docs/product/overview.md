# Lateness

Lateness следит за ритмом работы. Оператор заводит ожидание: интервал с допуском или cron с IANA-часовым поясом. Подтверждение приходит одним из двух способов:

- **Сигнал от задачи.** Внешняя задача в конце работы вызывает уникальный URL приёма. Можно отметить начало прогона (`begin`) и явный сбой (`fail`).
- **Проверка URL.** Сервис сам отправляет HTTP(S)-запрос по расписанию выбранным методом и сравнивает код ответа. Одиночный сбой повторяется; просрочка — только если за допуск не было ни одного успеха.

Если окно закрылось без подтверждения, сервис один раз сообщает об этом в каждый назначенный канал: почта (SMTP), webhook (HTTP) или Telegram. Возврат из «Просрочено» во «Вовремя» тоже приходит уведомлением.

Ожидание можно удержать: пока оно на паузе, просрочка не считается и проверки не идут. Возврат открывает новое окно от текущего момента.

У аккаунта может быть несколько проектов. В проекте свои ожидания и каналы; у каждого ожидания свой набор каналов. Удалённые проекты, ожидания и каналы скрываются, но их журнал сохраняется.

Регистрация закрыта: доступ выдаётся ссылкой-приглашением от администратора. Вход — по почте и паролю, через VK ID или Telegram. В профиле можно привязать и отвязать VK и Telegram, задать или сменить пароль.
