# Lateness

Сервис ждёт периодический сигнал от задачи или сам проверяет URL по расписанию и отправляет одно уведомление, если окно закрылось.

Модуль: `github.com/p0vidl0/lateness`. Бинарник `lateness` с ролями `serve` и `sweep`. Состояние — только Postgres.

Точка входа для команд — [Makefile](Makefile). Документация — [docs/README.md](docs/README.md).

```bash
make dev-up
```

После старта печатаются URL приложения, тестового SMTP-ящика и учётка сида. Регистрация закрыта: новые аккаунты — по ссылке из `make invite`.
